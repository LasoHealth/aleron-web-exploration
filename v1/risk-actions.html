Notes for review

fixed There was no way to log out, and no way to tell who was logged in. .prail__patient names the patient, so across 21 screens nothing said whose session this was and nothing ended it. v0 has both in its header, Dr. A. Okafor beside a Log out button, and the proposals dropped them when the header became a rail. A clinical surface that cannot say who is signed in cannot be handed to the next physician at the same workstation, which is the ordinary case in a clinic. The rail foot now carries the actor and the way out, under a rule, at the bottom where the least frequent act belongs. Proposed in section B as a domain.chart-rail addition, using the foot's existing exemption for a non-section action rather than claiming a new one.

fixed As bare underlined text the control was 15px tall, for the one act that ends the session. A text link is the sanctioned shape where a filled control will not fit, per register O5's fallback, but the hit area still has to be real: the label keeps its size and the target grew to 32px, with the same pointer: coarse guard the row-density variant uses restoring the full 44px floor on touch. Measured 14.35:1 flight-deck and 5.34:1 day.

new The action map itself. v0 has no counterpart at all: nothing in the shipped portal prices an action, so the version switcher marks v0 absent rather than pointing at a screen that would mislead the reviewer.

new Two value frames on one axis, declared on the axis (P7). Actions plot net; diagnostics plot value if reclassified. The diagnostics table below keeps odds and value in separate columns for the same reason: OGTT is 0.85 QALY at 4 % odds, and multiplying them into one number hides which half is small.

new The screen's one gold is the selection ring on Resmetirom. Everything else that could have taken gold, including the selected ledger row, uses the inset field instead.

gap The VO₂max ladder needs a colour the palette does not have. P2 fixes five signals and russet is not one of them. Carried as PROPOSED token.instrument-furniture (--p-ladder) in section B of physician-chrome.css with both register values, so the decision is visible for ratification rather than buried in a screen. Either the ladder gives up its own colour and rides on shape alone, or the palette gains a sixth signal.

gap PROPOSED domain.chart-legend (.plegend) and PROPOSED domain.proportion-bar (.pbar) also went into section B. A chart whose category rides on shape is unreadable without a legend, and components.css v0.5.0 declares none.

gap The reference surface's Decision-logic column prints the raw gate string, which for the v2 library items reads as machine enums (eligible=true, gate=confirmed_stage2_hypertension). Its own provenance helper says "provenance in words, never machine enums". This recreation uses the action library's prose basis and trigger copy for that column instead. Ratify the prose or ratify the enum, but not both.

gap In the shipped reference file, rerunActionLibraryScoring returns early on ENGINE_DERIVED_ACTIONS_BY_PATIENT, so AL-47M's map actually plots only six derived actions with a maximum net of +0.03 QALY. The v2 library additions that the rest of the surface assumes (GLP-1/GIP 1.48, supervised resistance training 1.10, BP pharmacotherapy 0.63) never reach the chart, and the AI screen's "Top action" degrades to Intensive lifestyle (DPP). This screen plots the library set that the catalog, the chart's own label table and the care-plan note all depend on. Fix the short-circuit upstream.
