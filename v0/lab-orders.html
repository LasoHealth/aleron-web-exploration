Baseline findings

finding This route’s tab strip has five items. lab-orders.blade.php omits the Trajectory entry from its $pageTabs array instead of rendering it disabled the way the other four chart pages do, so the strip silently changes width and the items shift under the pointer as the physician moves between tabs.

finding Tab strip variant 2 of 4: the inset holder gains a hairline border on this route only. Four hand-copied inline nav blocks means four visually distinct strips for one control.

finding Order status is the raw persisted enum: requisition_sent, collected, resulted. So is the test list, which prints catalog keys (lipid-panel, hba1c, hs-crp) rather than the display names the ordering form used one card above.

finding The genetics counseling attestation is a bare checkbox with a 3px inline top margin and no ring, no label styling and no error state. It is the legal gate on the whole genetics path and it is the least prominent control on the screen.

finding The test menu is sixteen unsorted checkboxes in a two-column grid with no grouping, no search and no indication of which tests any risk model is currently missing. The information gaps that would answer that are two routes away on Risk Models.

finding Both selects on this page are <select class="amd-input">. The design system ships .amd-select and .amd-select-wrap for exactly this, so the native disclosure arrow renders unstyled and the control is a different height from every field around it.

note The fifth table column has no header and holds the only per-row action, which appears solely when a result is available and unsigned. On a chart with nothing to sign the column is invisible and the table looks like a read-only ledger.

note Empty state is a single centred cell spanning all five columns reading No lab orders on file. There is no prompt toward the ordering form directly above it, and the shipping address block renders for a walk-in draw where it is not needed.

note Two independent ordering surfaces exist for the same act: this form, and the sign-and-send block inside the Care Plan note. They enforce different gates. Genetics can only be authorized here, and only this one has the counseling attestation.
